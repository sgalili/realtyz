---
name: Campaigns Unified Sent Feed
description: Campaigns page must use one global sent-post card list for UI-posted and native Facebook posts.
type: feature
---
On `/campaigns`, never separate recent/native Facebook posts from sent campaigns. All posts — whether created in Realtyz UI or posted natively on the connected Facebook Page — must appear in the same global sent-post card list, using the same collapsed-card layout, sorting, dedupe, thumbnails, metrics, expansion, and comment/reply UX.
