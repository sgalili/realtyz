---
name: Campaign card handling
description: Stable campaign cards, collapsed series, subtle first-comment warnings, text-only group counts and post-link fallbacks.
type: feature
---
Successful main posts remain successful when only the first comment fails; show a subtle warning labeled “הפוסט פורסם אך התגובה הראשונה לא נוספה”. Cards must not reorder when statuses or counters change. Related posts in a campaign share one master card and appear only when expanded. Group counter pills contain text only, e.g. “10 קבוצות”. Replace “ממתין בתור” with “בתור”. View-post actions use direct post links when available, otherwise the group's main page, opening safely in a new tab.
Expand series post cards inline directly below the main card, never in a floating overlay and without extra group-name rows. Keep repost at the far edge of the engagement row. One group shows an unframed, single-line shortened name with a full-name tooltip; multiple groups show a collapsed counter. Status icons reflect actual publication results: check for published, clock for pending/scheduled, error for failed.
