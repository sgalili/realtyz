# תיקון בידוד סביבת עבודה, פרופיל וחיבורי Onboarding

## מה יתוקן
- למנוע הצגה של פוסטים ממטמון של סביבת עבודה אחרת: מטמון הקמפיינים ייטען רק לפי מזהה סביבת העבודה הפעילה, ויימחק מיד בהחלפת משתמש או סביבת עבודה.
- להפסיק יבוא פייסבוק אוטומטי לחשבון חדש שאין לו חיבור עמוד פעיל; יבוא ורענון Meta יתחילו רק לאחר אימות binding ששייך לסביבה הפעילה.
- לתקן את בחירת סביבת העבודה הראשונית: חשבון חדש ייפתח בסביבה האישית והריקה שלו, ולא בסביבה קודמת שנשמרה בפרופיל או בדפדפן. חברות בצוות תישאר זמינה לבחירה ידנית בלבד.
- להקשיח את תצוגת הקמפיינים עם סינון מפורש לפי `workspace_owner_id`, בנוסף לכללי ההרשאה הקיימים.

## פרופיל ושמות
- להציג שם ידידותי בעברית במקום כתובת זמנית מסוג `@whatsapp.realtyz.local` בכל כותרות הפרופיל: `ללא שם` או `מתעניין/ת חדש/ה` לפי ההקשר.
- להעביר את שם הפרופיל שמגיע מ־Meta WhatsApp אל יצירת/עדכון המתעניין, בלי להחליף שם אמיתי שכבר נשמר.
- להפוך את עיגול תמונת הפרופיל ללחיץ, ממורכז ונגיש; להסיר את כפתור ההעלאה הנפרד ולהשאיר הסרה כאפשרות משנית.

## סיום הסיור וחיבורים
- להוסיף בסוף סיור המוצר מסך חיבורים קצר עם שני כפתורים מפורשים: חיבור Facebook ופתיחת הגדרת WhatsApp הרשמי של Meta.
- לא לבצע חיבור אוטומטי, לא להעתיק חיבור קיים ולא להפעיל OAuth בלי לחיצה של המשתמש.
- להשתמש רק ב־Meta Cloud API עבור WhatsApp. ה־QR בסיור יהיה קוד `wa.me` למספר הרשמי לאחר שהוא מחובר; אם טרם חובר, יוצג כפתור ישיר להגדרה הרשמית במקום QR מזויף או Green API.
- לפתוח אוטומטית את מקטע החיבור המבוקש בעמוד החיבורים כדי לצמצם את התהליך למספר שניות.

## ניקוי נתונים ואימות
- לנתק את סביבת העבודה החדשה המדווחת מסביבת אודי ולהחזיר אותה לסביבה האישית שלה, בלי למחוק נתונים של אודי.
- לבדוק שאין לחשבון החדש binding או חיבור Facebook משוכפל ושאין פוסטים של אודי שנגישים דרך הפיד שלו.
- לאמת בדפדפן: כניסה לחשבון החדש מציגה פיד ריק, אין חיבור Facebook אוטומטי, העלאת תמונה עובדת בלחיצה על העיגול, וסיום הסיור מציג את שני מסלולי החיבור.

## פרטים טכניים
- שינויי Frontend: `CampaignCenter`, `WorkspaceProvider`, רכיבי כותרת/פרופיל, `ProfileAvatarUploader`, `ProductTour`, `ConnectionsTab`.
- שינויי Backend: העברת `contacts[].profile.name` של Meta לתהליך יצירת המתעניין והקשחת שיוך סביבת העבודה.
- שינויי מסד נתונים: תיקון נתוני החברות/הסביבה הפעילה של החשבון החדש בלבד; שינוי מדיניות רק אם האימות יראה שהסינון המפורש אינו מספיק.
