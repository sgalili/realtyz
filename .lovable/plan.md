# תוכנית: האצת עמוד נכס ושיפור מבנה הפעולות

## מטרה
עמוד נכס יציג מיד את המידע שכבר שמור במסד הנתונים, יציג התקדמות ברורה לכל העשרה חיצונית, ויטען תמונות ומידע נוסף ברקע בלי לחסום את המסך.

## שינויים בממשק
- להעביר את כל כפתורי הפעולה לשורה העליונה, לפני כותרת הנכס.
- להוסיף לשורת הפעולות כפתור אייקון של פנקס ועיפרון; לחיצה עליו תגלול לאזור התקשורת בתחתית ותפתח אוטומטית את הכרטיסים הרלוונטיים.
- להפוך את ״הודעות מהירות״, ״הערה מהירה״ ו״ציר זמן הנכס״ לכרטיסים מתקפלים, סגורים כברירת מחדל.
- להקטין את כותרת הנכס ב־6px ולשלב את שם השכונה באותה שורה, עם שבירה תקינה במסכים צרים.
- להקטין את המחיר הירוק ב־6px ולהסיר ממנו הדגשה כבדה.
- להציב את שם בעל הנכס באותה שורה מול המחיר, ואת תאריכי הפרסום/העדכון בשורה שמתחת.

## טעינה מיידית והתקדמות
- להפריד לחלוטין בין קריאת רשומת הנכס המקומית לבין העשרת מקור, סנכרון בעלים וייבוא תמונות; אף פעולה חיצונית לא תחסום את התצוגה הראשונית.
- להשתמש מיד בנתוני הניווט ובמטמון React Query, ובמקביל לבצע קריאת DB קצרה וממוקדת; בעת כניסה ישירה לכתובת יוצג שלד תוכן יחד עם טבעת אחוזים מרכזית מהפריים הראשון.
- להציג טבעת התקדמות קבועה וברורה כל עוד חסר מידע בסיסי, ולא רק אחרי שהקריאה המקומית כבר הסתיימה. ההתקדמות תכסה שלבים נפרדים: רשומה מקומית, מטא־דאטה ותמונות.
- לקצר את זמני ההמתנה בצד הלקוח: להפסיק קריאות העשרה לאחר חלון קצר, להחזיר את הממשק מיד, ולהשאיר את העבודה האיטית ברקע.
- למנוע כפילויות: לא להפעיל במקביל סנכרון בעלים, מטא־דאטה וגלריה יותר מפעם אחת לאותו נכס.
- לשמור כל תוצאה שהתקבלה במסד הנתונים ולרענן את הכרטיס בהדרגה, כך שבכניסה הבאה המידע ייטען מקומית.

## הבהרת יעד הביצועים
- מידע שכבר נשמר במסד הנתונים יוצג מיידית, עם יעד של פחות משנייה בתנאי רשת רגילים.
- ייבוא ראשון ממקור חיצוני אינו יכול להיות מובטח בפחות משנייה בגלל זמני Yad2/Homely והרשת; הוא יתבצע ברקע עם התקדמות גלויה, בלי להשאיר עמוד ריק ובלי להמתין מעל דקה לפני הצגת תוכן.

## אימות
- לבדוק כניסה מכרטיס נכס וגם כניסה ישירה לכתובת נכס, במובייל ובדסקטופ.
- לוודא שהטקסט מופיע לפני התמונות, שהטבעת נראית מיד, ושכפתור הפנקס פותח וגולל לשלושת הכרטיסים.
- לוודא שהכותרת, השכונה, המחיר, הבעלים, התאריכים ושורת הפעולות אינם נחתכים במסך צר.
