# Accessibility preferences

TORAFF bundles `accessibility` 6.1.0 by Ran Buchnik under the MIT license. Its animation/media pause API is used without its toolbar, remote icon fonts or session storage. The application provides the Hebrew sidebar controls, high-contrast theme, readable font, text sizing, link highlighting, focus indicators and preference persistence.

Source: https://github.com/ranbuch/accessibility

These preferences are not a compliance certification or a replacement for semantic HTML, accessible content, screen-reader testing, keyboard audits, reflow testing or evaluation against Israeli Standard 5568 and applicable WCAG requirements. Canvas, third-party embedded content and animated bitmap media require separate evaluation. No paid license or SaaS is required.
